# 猜数字小游戏

## 项目简介
这是一个用 Python 编写的命令行猜数字小游戏。电脑随机生成一个 1 到 100 之间的整数，玩家输入猜测，程序提示“大了”或“小了”，直到猜中，并统计猜测次数。

## 功能
- 随机生成 1 到 100 的整数
- 接收用户输入
- 提示“大了”或“小了”
- 猜中后显示答案和猜测次数
- 对非数字输入进行简单提示

## 运行环境
- Windows 10/11
- Python 3.x

## 运行方法
1. 按 Win + R，输入 cmd，回车。
2. 进入项目目录：
   cd /d D:\play_do\first
3. 运行程序：
   python guess_number.py
   或：
   py guess_number.py

## 游戏规则
1. 电脑随机生成一个 1 到 100 的数字。
2. 玩家输入自己猜的数字。
3. 如果猜大了，程序提示“大了”。
4. 如果猜小了，程序提示“小了”。
5. 猜中后，程序显示答案和总猜测次数。
